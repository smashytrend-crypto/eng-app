# Speak by Summer

Osobista aplikacja PWA do nauki **mówienia** po angielsku: gotowe zwroty w kontekście, powtórki FSRS,
ćwiczenia PL → EN, mówienie na głos. Działa offline na telefonie, dane zostają w urządzeniu.

- Wymagania: [`docs/SPEC.md`](docs/SPEC.md)
- Jak opublikować i zainstalować na telefonie: [`docs/DEPLOY.md`](docs/DEPLOY.md)
- Dla Claude (struktura, treści, jak dodać moduł): [`CLAUDE.md`](CLAUDE.md)

```bash
npm install
npm run dev        # serwer deweloperski
npm test           # testy
npm run validate   # walidacja treści
npm run build      # build produkcyjny
```
